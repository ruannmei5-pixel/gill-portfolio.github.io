# Gill — From Minus to Peak

Personal portfolio site for Ragil Vahlevi ("Gill"), a Computer, Network &
Telecommunication Engineering (TJKT) student. Built with Astro,
TypeScript, and Tailwind CSS.

This archive corresponds to **Prompt 01**: project foundation, design
system, component architecture, and static page structure. No backend,
no AI assistant, and no real project/achievement data have been added
yet — see `PROJECT_CONTEXT.md` for full details.

## Requirements

- Node.js 18.17+ (or 20+) recommended
- npm

## Getting started

This project was built in a sandbox without network access, so
dependencies have **not** been installed and the build has **not**
been verified yet. Before doing anything else locally:

```bash
npm install
npm run dev       # start the local dev server
npm run build      # type-check (astro check) + production build
npm run preview    # preview the production build locally
```

If `npm install` or `npm run build` surface errors, they have not been
seen or fixed yet — this is the first real compile/build this project
will go through.

## Interactive terminal

The Hero's terminal (`gill@portfolio`) is a real, simulated command
terminal — type `help` into it for the full command list (`whoami`,
`about`, `journey`, `skills`, `projects`, `experience`, `education`,
`achievements`, `contact`, `status`, `date`, `clear`). It's
frontend-only: no AI, no API calls, no backend, and command history
lives only in the browser tab's memory. See `src/data/terminal.ts` for
the command logic and `PROJECT_CONTEXT.md`'s Phase 08 notes for full
details.

## Ask Gill AI

A visitor or recruiter can ask questions about Gill — his journey,
skills, projects, and background — either in the "Ask Gill AI" section
on the homepage (`#ai`) or on the dedicated `/ai` page (same component,
two access points). As of Phase 09 it's a fully **client-side,
rule-based** assistant (`src/lib/aiEngine.ts`) that answers only from
the site's existing, verified data (`src/data/aiKnowledge.ts` — a thin
knowledge layer over `profile.ts`, `journey.ts`, `skills.ts`,
`projects.ts`, `education.ts`, `achievements.ts`, `experience.ts`).
There is **no AI provider, no API key, and no network call** — nothing
here is generated by a real LLM yet, and it never invents a fact it
can't trace back to the data files (e.g. it explicitly says Gill's
portfolio doesn't list a formal employer, and that his PKL isn't
completed, rather than guessing). See `PROJECT_CONTEXT.md`'s Phase 09
notes for the full architecture and the plan for connecting a real AI
provider later without changing the chat UI.
